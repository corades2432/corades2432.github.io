Privacy Policy

Last updated: October 30, 2026

This policy explains how the CORADES desktop application ("CORADES", "the application") handles information, including information accessed through Google APIs.

Data stored by the application

Business data entered into CORADES (customers, appointments, payments, services, staff and similar records) is stored in a database file on the user's own computer. The developer of CORADES does not operate a server that receives or stores this data.

Google user data we access

Google features are optional and are only used after the user signs in with Google and grants permission. CORADES requests the following permissions:

  • Basic profile (openid, email): to show which Google account is connected.
  • Google Calendar – calendars created by the app (calendar.app.created): to create a dedicated appointment calendar and create, update and delete appointment events in it. CORADES cannot see the user's other calendars.
  • Google Drive – files created by the app (drive.file): to upload, list, download and delete encrypted backup files and helper files that CORADES created. CORADES cannot see the user's other Drive files.

How we use Google user data

Google user data is used only to provide the features the user requested: appointment calendar synchronization and backup/restore. Google user data is not sold, not used for advertising, not used to train AI or machine learning models, and not transferred to third parties.

CORADES's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security

Google sign-in tokens are stored only on the user's computer and are used to call Google APIs directly from that computer. Backups uploaded to Google Drive are encrypted with a password chosen by the user. Google account passwords are never seen or stored by CORADES.

Data retention and deletion

Users can disconnect Google in the application at any time. Access can also be revoked from Google Account → Third-party connections. Calendar events and Drive files created by CORADES stay in the user's own Google account and can be deleted there by the user. Local data can be deleted by removing the application and its database file.
